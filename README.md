# Azure E-Commerce Lakehouse Platform

## Project Overview

A production-grade end-to-end Azure Data Engineering project demonstrating:

- Azure Data Factory
- Azure Data Lake Gen2
- Azure Databricks
- PySpark
- Delta Lake
- Azure SQL Database
- Power BI
- Azure DevOps CI/CD

## Architecture

Source Systems
→ Azure Data Factory
→ ADLS Bronze
→ Databricks
→ ADLS Silver
→ Gold Layer
→ Azure SQL
→ Power BI

## Features

✅ Metadata Driven Ingestion

✅ Incremental Data Loading

✅ Delta Lake MERGE

✅ Data Quality Validation

✅ Monitoring & Alerting
