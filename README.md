# 🚀 Azure E-Commerce Lakehouse Platform

## 📌 Overview

A production-grade end-to-end Data Engineering project built using Azure cloud services and Lakehouse architecture.

This project demonstrates how to ingest, transform, validate, and serve data for analytics using modern Azure Data Engineering tools and best practices.

---

## 🏗 Architecture

Source Systems
↓
Azure Data Factory
↓
Azure Data Lake Gen2 (Bronze)
↓
Azure Databricks + PySpark
↓
Silver Layer
↓
Gold Layer
↓
Azure SQL Database
↓
Power BI Dashboard

## 📂 Medallion Architecture

### Bronze Layer
- Raw source data
- Immutable storage
- Schema drift allowed

### Silver Layer
- Cleansed data
- Deduplication
- Standardized formats

### Gold Layer
- Business-ready datasets
- Aggregations
- Reporting layer
